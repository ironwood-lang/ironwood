## What S4 must still do

The helpers are prerequisites, not ports. S4 keeps these obligations:

- Port OptimizedTraceMetadata.inject, SharedTraceOrder, NativeTarget,
  LlvmEmitter's text and TracePlan, and TlsDependency with these helpers, and
  compare their outputs with the Java baseline on the same corpora.
- Reproduce Java's `stringPropertyNames()` hash order wherever a report
  names the first failing entry (TlsDependency and BridgeNativeSupport
  checksums), or sort and record the difference.
- Write the launcher: pass the canonical compiler location to `Installation`,
  generate `BuildIdentity` with build-identity.sh, and in the shell driver own
  the temporary LLVM file, the optimization report alias check, SDKROOT and
  the LLVM and Clang processes, compiling runtime objects directly.
- Meet S4's exit: native O0 and O3 programs, SelectiveInlining candidate sets
  and `alwaysinline` attributes equal to the Java compiler's with selective
  inlining on and off, and the complete S4 J0 build-capacity qualification on
  a recorded seed, since J0 cannot compile the accumulated port (M3.2).

## Retained limits

These are conservative rejections, not safety gaps:

- A wrapping `ByteBuffer` keeps its array from being freed; the trace reads
  use `Bytes` instead.
- A Properties parse owns a copy of its text; a borrowing parse would keep the
  text from being freed.
- Creation-array roots must be fresh objects no call has seen, so each
  recorded root is a copy of the probed Path.
- The M3.1 and M3.2 retained limits still apply.

## Handoff run

One run on a fresh `git archive` of 8ec1a836: the strict `scripts/build.sh`,
`javac --release 21 -Xlint:all -Werror` over every compiler test source, and
23 focused tests: the eleven M3.3 tests; `numeric standard-library helpers
run at O3` and the IronDocs test for the new public method; the
reference-bound audit over every port source; the four SelectiveInlining
tests and the native target, shared trace order and version tests as
unchanged Java consumers; and the SHA-256 and ByteView tests whose helper the
TLS checks reuse. The classification, one compilation of all 168 port sources
with both pilot adapters (no diagnostics), and the diff and license audits
also ran. Unsafe programs were compile-only; no full suite or hosted build
ran.
