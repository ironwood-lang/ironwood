## What the inventory holds

[IrModel.iron](../../../compiler/src/main/ironwood/ironwood/compiler/port/IrModel.iron)
is generated by [IrModelInventory](../../../compiler/src/test/java/ironwood/compiler/IrModelInventory.java)
from `compiler/src/main/java/ironwood/compiler/ir` by reflection:

| Function | Content | Count |
| --- | --- | --- |
| `Record` | every IR record | 113 |
| `root(Record)` | the sealed root it implements: 85 instructions, 7 terminators, 6 operands, 15 other records | 113 arms |
| `javaName(Record)` | the Java simple name, for diagnostics that print `getSimpleName()` (D266) | 113 arms |
| `components(Record)` | `name:JavaType` in declaration order | 447 components |
| `walked(Record)` | the components the reflective walkers follow | 113 arms |
| `Enumeration`, `constants(Enumeration)` | every IR enum and its constants | 20 |

The three root counts equal the pilot lists in `OperationVariants`
(D260), which keep their admission functions; both are derived from the
same Java declarations.

## Coverage proof

`IR model inventory fails closed on untreated variants` mutates the file five
ways: removing a `walked` arm, a `root` arm or a `constants` arm, adding an
untreated record and adding an untreated enum. Every mutation fails
compilation with the exhaustiveness diagnostic in `off`, `warn` and `error`.
`IR model inventory matches the Java model` regenerates the file in memory and
requires byte equality, so a changed Java record, component or enum constant
fails until the file is regenerated.

## Walk contract for S2

`walked()` restates `ClosedWorldPruner.scanRecord`'s descent rule as data:
follow components typed as IR types, operands, the other sealed roots and
IR-package records, directly or through `Optional`, `List` or `Set`. Maps,
`String`, primitives, enums, `Number`, arrays and `SourceSpan` are not
followed. For example, `IrCallInstruction` walks `result,returnType,arguments`
and not its specialization map, and `IrType` walks
`typeArguments,elementType,typeParameterErasure,wildcardBound`. S2 replaces
the Java baseline's reflection with explicit traversal that follows exactly
these lists (comparing against the reflective result), then ports it with an
exhaustive switch over `IrModel.Record` whose unported variants are named
rejections.

## Regeneration

```sh
javac -d workspace/m3/model/gen -cp compiler/build/classes compiler/src/test/java/ironwood/compiler/IrModelInventory.java
java -cp workspace/m3/model/gen:compiler/build/classes ironwood.compiler.IrModelInventory
```

Run from the repository root after `scripts/build.sh`. The generator is a
development tool; the checked-in Ironwood source is what native builds use.
