# Source joins and remaining review boundary

reconciled/manifest.json pins all 460 original/current source files and the
scoped review artifacts. Its API/call, syntax and capture ledgers preserve each
original row and add literal UTF-16 source, declaration/type, concrete source
consumer and preparation/migration gates. The joins contain 712 declarations,
30,979 external call sites, 12,413 syntax sites and 3,054 captured-symbol rows.
They distinguish reviewed scoped contracts from unresolved caller obligations.
They are a coverage reconciliation, not completion of global contract review.

The selected frontend's exact method/site closure overlays default staging.
Selected bounded snapshot/restore/merge and effect methods have their M1.1,
M1.2 or M1.3 prerequisite and M2.1/M2.2 first consumer, with the finite model
restrictions attached. Other methods in those same files retain later gates.
In particular, nonempty captureJoinEvidence bodies and JoinPath/JoinAlternative
roles remain later; general effect validation, virtual/class target resolution,
unwind, rendered-release and observerProjection helpers are not selected by the
finite effect input. Constructor source spans select data treatment only under
OPERATION_FACTORY_CONTRACTS.md; arbitrary constructor inputs remain later.

Exact attributed method calls can bring a Bridge helper ahead of its standalone
S7 module. The route is preserved as call sites, including method references.
This route does not prove branch execution, generated-body coverage or complete
virtual dispatch. Those frontiers remain unresolved before the dependent native
consumer. Preparation milestones and migration consumers are distinct fields.
Source/type/name/numeric/digest/backend and host/artifact demands still require
their precise M3/M4/M5/M6 owner review; folder defaults alone cannot finish it.

Captures retain their callback source and closest enclosing call. An outer local
or parameter differs from an implicit receiver member access. The latter retains
the receiver and reads its member at invocation; copying the current field value
would require a separate proof. Immediate/lazy effect callback contracts join
their exact enclosing API proof. Retained holder contracts remain independently
scoped. The 65 selected captured rows have source contracts, with native allocation
and accepted/rejected cleanup evidence still required in M2.2.

The hash join preserves 849 origins, 2,957 traversal records and all 31,325
origin/traversal contributions. Each has a witnessed path through the original
flow graph; 7,142 source edges are referenced. Types, null-construction rules,
record/interface headers and equality obligations stay attached to origins.
Paths are conservative source obligations, not equivalence or extensional proofs.
The private evidence/effect/tracker proofs apply only to their named contribution.
The keyword table remains proved lookup-only under its source proof. The bounded
ownership facts remain conditional on the actual LOCAL_NEW/empty-path/one-conflict/
pre-stopped-budget/keyed-output domain. Its general first-event, prefix, child
and competing-owner paths stay unresolved before S3.

Ninety-eight contributions into restricted IR constructors originate outside the
finite operation factory. The factory constructs empty type/specialization/class
membership and ordered direct builders, so those original producer graphs are
excluded from its input. This is conditional factory exclusion, not a global
order-independent classification. General origins/constructors remain blocked.

current-delta/ preserves seven freshly attributed FunctionAnalyzer tables and
the two pinned Java 21 commands/tool source. Unchanged source regions map 14,464
calls exactly across UTF-16 offsets. Five old and ten current enclosing changed
expressions include two comment-only min/orElse expressions, direct builder
construction and the ordered-copy helper. The helper's new immediate capture
and unmodifiableMap/null-check calls retain ordered/DELTA.md's M1/M2 contract.
All original IDs/tables and both frozen seeds remain unchanged.

Reproduce after reconstructing the frozen installations:

```sh
python3 scripts/self-hosting/reconcile-current-delta.py
python3 scripts/self-hosting/review-operation-factory.py
python3 scripts/self-hosting/reconcile-inventory.py
python3 scripts/self-hosting/reconcile-hash.py
python3 scripts/self-hosting/qualify-reconciliation.py
```

The current delta first needs the retained Inventory command inputs, as recorded
in its commands.json; it is attribution work, not a new resource measurement.
The qualifier checks every source/site join, every original graph witness, all
selected call/capture gates and four controls: dropped selected proof, frontend
moved to a later gate, removed flow edge and bounded proof promoted to general
ordering. The ledger's unresolved fields are visible work, rather than passed
contracts. M0.2/M0.3/S0 stay open for the remaining exact global reviews and final
handoff reconciliation. No native helper/compiler implementation is delivered.
