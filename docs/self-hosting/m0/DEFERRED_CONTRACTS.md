# Source-backed deferred contracts

The final inventory in deferred/ supplements the original reconciliation without
changing its raw IDs, grammar or source evidence. Each exact API declaration has
all source call IDs, typed receivers/operands, source consumer, B owner, preparation
phase, first migration consumer and a unique fixture. Each syntax/capture site and
hash-origin/traversal contribution has the same admission boundary. Unresolved
means the named consumer cannot be declared portable until its contract passes.
It is a recorded later obligation, not an equivalence proof or an M0 native task.

Exact M1/M2 selected sites retain their scoped contracts and finite input models.
All other uses remain later, including uses in selected files. For a selected
factory, source branches outside its admitted input are explicitly excluded;
general producer/constructor paths remain unresolved. Every later API entry
contains actual source, declaring/instantiated types and captured symbols where
present. A dynamic null/alias/lifetime field remains unknown rather than being
filled with a safe assumption. The required fixture must resolve that exact
unknown, using the source operation and its first consumer.

The fixture identifier includes the declaration/site or origin/traversal IDs and
actual source method. It is a required test design, not an assertion that a test
already exists or has passed. The preserved operand/source facts make its admitted
domain reviewable. The resolution checklist is specialized by dependency family,
with source literal/type/symbol evidence, and includes normal/failure ownership.
M6.3 reconciles every remaining entry before its actual consumer qualification;
it does not postpone an earlier prerequisite to M6.3.

## Branch-sensitive routes

Main.run lines 51-54 dispatch standalone Bridge commands. CompilerPipeline's
analyzeForBridge/compileBridge entries and bridgeAnalysis/proxies branches are
separate from ordinary source compilation. The final route graph does not promote
their callees to S4 merely because Main or an unused facade entry mentions them.
Exact semantic callers remain in the graph and can bring Bridge helpers to S3.
An unresolved virtual/generated/conditional route blocks admission at that caller;
the ledger does not claim closed-world branch coverage from an attributed edge.

SourceSetLoader.locateClass and archiveCache, Main.writeClassOutputs, IronClass/
IronJar, and StandardLibrary's archive/class roots are S6 facilities. S4's private
adapter uses source inputs, no explicit class types or classpath, source roots and
explicit installation/build identity. It must replace the bundled-source route
without executing StandardLibrary.discover's archive preference or locate's
locateClass fallback. General SourceSetLoader/StandardLibrary are not declared
portable. SourceFile.read and DiagnosticFormatter remain outside the selected
in-memory frontend but precede source-only S4. A classpath or artifact branch
cannot silently enter that adapter; its first consumer must satisfy S6 instead.

NativeBackend/LlvmToolchain/MacNativeTools and tool-discovery methods are native
driver services. The S4 source-only route emits LLVM and uses external qualified
shell orchestration. NativeBackend's cache policy and digest/publication contract
must be resolved before electing M4.3 integration; none is implemented in M0.

## Unresolved ordering and captures

All 849 original hash producers keep actual key/element types, source equality
declarations and construction null rules. All 31,325 contribution paths keep the
original witness edges, source traversal and named consumer. A zero-discovered-
traversal producer remains unresolved unless its scoped source proof rules out
escape. A linked copy or stable sort is not an order proof for its upstream
producer, equal keys, first diagnostics, IDs, effects or bounded prefixes.
Required fixtures vary collisions, capacity/resize and insertion order, then
either prove extensional results or specify deterministic order before the first
observable choice. Conditional selected proofs stay conditional.

Every captured-symbol row retains its exact callback source, source call and
symbol/type. Receiver member accesses retain the receiver and read its field at
invocation. Later fixtures must determine actual holder/result/last consumer,
immediate/lazy/retained timing, mutation/reentrancy and exception effects, measure
callback/state allocation, and pair independent cleanup with rejected premature
capture/holder frees. No unknown effect is granted non-retaining status.
