# M0 checkpoint and permitted M1 scope

M0 fixes the reference, source contracts, finite input models and budgets. It
permits only the M1 prerequisites below. M1 and M2 are not implemented or
qualified by this evidence. S1/G1 remains closed until the native workloads and
their complete equivalence, allocation, cleanup and resource evidence pass.

pilot-handoff.json.gz enumerates the exact 1,330 selected external call IDs,
selected syntax/capture rows and hash contributions from the final source ledger.
It pins their per-site proofs/gates and all model/corpus/budget inputs. This is
an enforced method/site boundary, not whole-file portability. The original
frontend closure is 376 methods/groups, 3,154 calls and 868 external calls across
68 declarations. Its 119-value model covers fields/variants independently of
the observed corpus. The bounded operation model has 13 selected, 31 restricted
and 189 later-only declarations; each field/variant retains its explicit role.

Current D247 adds immediate Map.forEach, null validation and unmodifiable ordered
membership to copyArraySlots. current-delta and ordered/DELTA.md pin those exact
source calls separately from original IDs. M1.1's private immutable membership,
M1.2 local ordered traversal and M1.3 immediate callback rewrite implement that
bounded contract. General upstream first-event/child/prefix/competing-owner

Required M1 evidence includes Java-equivalent content/null/failure order, normal
and partial-construction rollback, allocation counts and accepted independent
cleanup paired with rejected frees of still-observed builders, fields, payloads,
snapshots and captures. No unknown effect becomes non-retaining. Hot lowering
changes, if actually needed, retain D132/D133, O3 inspection and the relevant
deterministic benchmark. The source-ready checkpoint does not waive those checks.

## M2 consumers and fixed input boundary

M2.1 ports only in-memory SourceFile.of/lineText, source positions/spans, diagnostic
values, Lexer.lex, Parser.parse and the selected AST constructor model. Input is
strictly decoded UTF-8 with the frozen logical-name contract. SourceFile.read,
DiagnosticFormatter, TypeName rendering/locale/split, DeclaredTypes, PatternFlow
and general semantic helper methods remain later. The private adapter must reject
an unqualified path, type/variant or entry rather than invoking its general body.

M2.2 executes actual seven-field snapshot/save/mutate/restore/merge on 8/32/128
LOCAL_NEW identity nodes, four shapes, 64 iterations and 128 retained branch
versions plus the merged version. It admits one pool-conflicting key, empty
JoinPath/JoinAlternative, immutable shared children without general child
selection and keyed result projection. Tight explanation budget stops during
ordered setup before joins; arbitrary bounded prefixes are excluded. The private
evidence store and effect observer are separately measured. The effect factory
admits only OPERATION_MODEL's Node/METHOD/entry-block/DIRECT/fixed-foreign/reference
roles with empty class/type/specialization input, ordered operands and explicit
rejection of every other role. Chains and actual cycles use 8/32/128 functions
with width 65 plus sixteen functions with widths 8/257, observer off/on.

M2.3 uses --unfreed=warn, retaining complete compile/link logs, per-command and
unique-site missing-free classifications and local suppressions. Mandatory safety
errors stay errors in every mode. Retire native temporary backing and callback
state after the actual last consumer; zero outstanding retired temporary bytes
is independent of warnings. Complete safe/unsafe source outcomes remain frozen
without using Java as an oracle for reclamation.

The 36-source frontend corpus, retained actual operations and PILOT_BUDGETS.md
fix the qualified macOS arm64 M5/32-GiB limits before native evaluation: frontend
2 seconds/1 GiB; ownership/evidence/effect 1 second/512 MiB, with 250/250/500-ms
operation caps; native main stack 8,176 KiB. Every required scale/mode gets two
fresh repeats. Missing byte/depth evidence stays missing; sampled heap/frame
observations are not native allocation or stack-byte high-water measurements.

M1.1/M1.3 deliver and hash helper .iron sources. M2.1 adds translated Lexer/
Parser/AST consumer sources and completes the combined source manifest, then
captures its fresh Java reference before native evaluation. The entire real
bundle must run in one invocation retaining its input/output graphs under the
same 2-second/1-GiB/stack caps. Per-file or example-only success cannot substitute.
M0 does not translate that future bundle or claim to have measured it.

## Remaining consumers

Every unselected API/syntax/capture/hash demand stays source-backed and blocked
at DEFERRED_CONTRACTS.md's exact B/M/S consumer. M3 handles general representations,
semantics/digests and source-only LLVM emission; M4 supplies native filesystem/
process services; M5 handles codecs/artifacts/docs; M6 handles standalone Bridge
and final preparation reconciliation. A genuinely earlier admitted caller brings
its prerequisite forward. The source-only S4 route excludes archives/classpath,
Bridge dispatch and native process APIs, using explicit installation/build inputs
and qualified shell orchestration. No other milestone starts with this handoff.

M0 source checks replay from immutable git/blob inputs as REPLAY.md describes.
Original and D247 identities and all failed/provisional captures stay intact.
No reference is changed to hide order, diagnostics, IDs or generated bytes.
