# Ironwood standard-library testing module

This optional standard-library module provides assertions, assumptions,
explicit test-suite registration, and deterministic native reporting. It ships
as `lib/ironwood-testing.ironjar` but is not added to production compilations
unless the programmer selects it with `-cp`.

See [Testing Ironwood code](../../../docs/TESTING.md) for the API, design
constraints, suite audit, migration status, and verification commands.
